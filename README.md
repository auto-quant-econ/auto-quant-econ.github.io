# Auto Quant Econ

Auto Quant Econ is an open, modular knowledge base for quantitative spatial economics. It explains seven model-component families, documents concrete specifications, and maps complete papers back to those components.

Public site: <https://auto-quant-econ.github.io/>

## Knowledge structure

1. Preferences
2. Production Technology
3. Commodity Trade
4. Technology for Idea Flows
5. Migration
6. Endowments
7. Equilibrium

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000/>.

## Verification

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

## Contributing

Start with a structured GitHub issue, create a short-lived branch, and open a pull request into `main`. Content changes receive editorial review; application changes receive technical review. See [the content guide](docs/content-guide.md) and [citation guide](docs/citation-guide.md).
