# Citation Guide

## Primary sources

Prefer the published paper, official working-paper version, author-hosted replication archive, or publisher record. Secondary summaries may help discovery but do not support substantive model claims.

## Reference records

Store bibliographic metadata once in `content/references/references.json`. Use a stable lowercase ID and include the full citation, title, authors, year, stable article URL, and public code URL when available.

## Page annotations

Do not append an unexplained bibliography. State what each cited paper contributes to the current page: foundational formulation, quantitative implementation, parameter evidence, extension, critique, or replication.

## Equations and claims

When a statement depends on a particular formulation, identify the source section or equation in the prose or pull-request description. Preserve the paper's economic meaning when translating notation into the site's standard symbols.
